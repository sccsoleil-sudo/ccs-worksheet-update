# CCS Worksheet Update

Daily tool to enrich S4 Excel exports, find new lines, check discrepancies, and compare against existing worksheets.

## Free website (GitHub Pages — JavaScript)

Open: **https://sccsoleil-sudo.github.io/ccs-worksheet-update/**

Runs in your browser (upload Excel → download results). No Python install needed.

## Run Streamlit on your Mac (optional)

Double-click `Run CCS Tool.command`, or:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/streamlit run app.py
```
